# Guía Etapa 2 - Acceso Simple

## 🎯 Cómo Acceder a la Guía

### Para Estudiantes

**URL Directo:**
```
http://localhost:3000/guia2    (Desarrollo local)
https://tu-dashboard.onrender.com/guia2    (Producción)
```

**Simplemente:**
1. Profesor dice en clase: "Acceder a /guia2"
2. Escribir la URL en navegador
3. Se descarga el PDF automáticamente

### Para Profesor/Admin

**Para compartir el link:**

**Local:**
```
http://localhost:3000/guia2
```

**En Render:**
```
https://tu-dashboard.onrender.com/guia2
```

Copiar y compartir con estudiantes vía:
- Classroom / Canvas
- Email
- Mensaje de Teams/Discord
- Anuncio en clase

## ✨ Ventajas

✓ No hay botón visible en home - sin confusión
✓ Link compartido explícitamente - control total
✓ URL simple y fácil de recordar
✓ Funciona igual en local y producción
✓ Cero complejidad técnica

## 🔄 Flujo

```
1. Profesor comparte: https://dashboard/guia2
2. Estudiante abre link en navegador
3. PDF se descarga automáticamente
4. Estudiante sigue guía
5. Implementa servicio Etapa 2
```

## 📝 Ejemplo en Clase

```
Profesor: "La guía está disponible en /guia2"
Estudiante: Abre navegador
Estudiante: Escribe: https://dashboard.onrender.com/guia2
Estudiante: Descarga PDF
```

---

**Sistema simple, directo, sin botones ni variables de configuración.**
